# 🛒 Resell Hub

Resell Hub is a web-based online reselling platform developed using **Python Flask**, **SQLite**, **HTML**, **CSS**, and **Bootstrap**.  
The platform allows users to buy and sell second-hand products with a bargaining system between buyers and sellers.

---

# 🚀 Features

- User Registration and Login
- Seller and Buyer Roles
- Product Upload with Images
- Product Management (Add/Edit/Delete)
- Bargaining / Offer System
- Accept or Reject Offers
- Automatic Order Generation
- Final Negotiated Price System
- Purchase History and Receipt
- Responsive User Interface

---
